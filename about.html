1. 这个网站解决什么问题？

小天 VPS 雷达是一个面向开发者与进阶玩家的独立云服务器 / VPS 信息整理与开源工具项目，不是商家代理，也不代收款项。我们把首期年价、循环续费口径、3 年总持有成本（TCO）、支付方式、备案边界、4 小时全网线索与验机工具放到同一套工程台里，帮你在下单前把账算清。

2. 信息怎样进入正式优惠榜？

  1. 来源分层：优先云厂商官方活动页与帮助中心文档；社区原始促销帖单独标注来源；第三方资讯站仅作线索。
  2. 续费绝不猜测：明确区分循环同价（Recurring）、限期锁价（如截至 2029-03-31）、限同价续费 1 次与未知续费。
  3. 三态生命周期：在售精选 / 观望区 / 已过期下架档案。已截止优惠码（如 CloudCone PREBF26）立即移入下架档案留底比价，不混入在售榜误导点击。
  4. 自动线索隔离：Cloudflare Workers 每 4 小时从 9 大公开 RSS 聚合线索并用 Workers AI 做中文速读，始终标注“未核验”，不自动冒充正式报价。

3. 商业合作与联盟推广披露

为覆盖域名维护与持续更新精力，本站部分商家直达按钮（如 RackNerd、阿里云、CloudCone、Evoxt）包含官方联盟推广参数，均已在页面清晰标注「官网推广直达」且在 HTML 中严格设置 rel="noopener noreferrer sponsored"。

通过推广链接购买不会增加你的任何购机费用；所有卡片的“原始核验来源”均直达不含推广参数的官方活动/文档原页。编辑排序、续费警示与过期下架决策完全独立，不受推广合作影响。

4. 开源架构与开放数据接口

本站源码以 MIT 协议开源在 github.com/fightlife228/xiaotian-vps-radar（运行在 Cloudflare Workers + KV + 免费 Workers AI 额度上）。所有结构化数据均可直接读取：

  • 在售与归档结构化快照：/data/offers.json

5. 发现涨价、无货或想提交新优惠？

云厂商活动与库存随时变化。如果你发现任何价格变动、续费条款差异、链接失效，或希望推荐新的高性价比循环同价机型，欢迎直接前往 GitHub Issues 提交反馈或提 PR ↗，核验后会第一时间修订并写入变更日志。

6. 合规与隐私边界

本站无用户注册、无评论追踪、无第三方广告弹窗，计算器与 Prompt 生成器均在本地浏览器运行；主题偏好仅保存在你本地的 localStorage。本站仅整理公开云服务器信息，不提供账号代购、代理服务或任何未授权抓取。
